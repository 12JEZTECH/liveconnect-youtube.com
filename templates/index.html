Remote phone camera — setup guide

Remote phone-to-studio video requires a secure WebRTC signalling and TURN service. That relay is not included in this first source-code release. For now, use OBS Virtual Camera or connect the phone as an OBS camera source on the same network.

Before going live

  • Your YouTube channel must be eligible for live streaming and have live streaming enabled.
  • Google OAuth must be configured in Google Cloud with YouTube Data API v3 enabled.
  • Set the exact callback URL to /auth/google/callback on your deployed domain.
  • Keep the RTMP stream key private. Anyone with it may be able to broadcast to your stream.
  • Use a paid Render instance for sustained live workloads; this app creates YouTube broadcasts but OBS sends the actual video feed.
